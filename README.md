# 180DC skills

Skills for 180 Degrees Consulting Delft-Rotterdam. You upload one to Claude, and it helps you think
harder about your own work. **A skill never writes the client's words, and it never grades you.**

## Skills

| Skill | What it does | State |
|---|---|---|
| `180dc-review` | Reviews a deck. **Lead mode** for team leads; **student mode** is a simpler check against the chapter's principles | Being built: lead mode for 27 Oct, student mode for 3 Nov |
| `180dc-coach` | Socratic practice on your own work | Slot only, not built |
| `180dc-visuals` | Title first, then a chart that proves it | Slot only, not built |
| `180dc-research` | Desk research where every claim carries a source | Slot only, not built |
| `180dc-ai-explainer` | Explains an AI topic, from the chapter's AI-learning material | Slot only, not built |

Slots are listed here rather than as folders. Any `SKILL.md` someone zips becomes a live skill, so an
empty placeholder would be a broken skill.
